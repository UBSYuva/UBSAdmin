How to Get the .APK File

1 Method 1: Automatic 1-Click Cloud APK Build (Free on GitHub) Recommended

We have pre-configured a GitHub Actions Workflow inside the zip at .github/workflows/build-apk.yml. You don't need Android Studio or SDK installed on your computer!

  1. Upload the downloaded folder to a GitHub repository.
  2. Click on the Actions tab in your repository.
  3. Select "Build Android APK" and click "Run workflow".
  4. Once complete (~2 mins), download the generated UBS-Member-App-Release-APK directly!
2 Method 2: Local Build via Flutter CLI / Android Studio

If you have Flutter installed on your PC or Mac, open terminal in the project folder and run:

# 1. Fetch dependencies
flutter pub get
# 2. Build release APK
flutter build apk --release

The output file will be generated at: build/app/outputs/flutter-apk/app-release.apk

3 Method 3: Direct Phone Install without APK (PWA) Instant

Open this web app link on Google Chrome on your Android phone, tap the browser menu (⋮), and tap "Install app" or "Add to Home screen". It installs like a native app immediately!
